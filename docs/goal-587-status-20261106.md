## 可重用入口

所有候选、日志、合成资料在登记实例 `version587-20261105` 的缓存；不读邮件、账号或凭据内容。构建使用已有便携工具和 canonical lease。

- `version587/goal-prepare-cold.cjs` 生成隔离的辅助模块源码，不覆盖已有 C 文件改动；随后用 `secondary-windows/compose-native-gate/build-native-v2.ps1 -SourceDirectory ... -OutputGroup ...` 构建。
- `goal-firstrestore.cjs`、`goal-paper.cjs`、`goal-pen.cjs` 均校验固定输入和修改范围。
- `goal-verify-paper.cjs` 使用隔离 Edge 测试合成编辑内容的实际导出函数；不连接 Foxmail。
- `goal-install-firstrestore.ps1` 管理首次托盘版及已拒绝缓冲试验的带校验切换。不要重新安装 Buffer 试验作日常版。
- `goal-install-paper.ps1 -Preflight` 校验当前候选安装计划，`-Rollback -Preflight` 校验回退。去掉 `-Preflight` 才实际替换。回退恢复已接受的首次托盘 EXE 与旧 CSS，辅助 DLL 保持不变。
- `restart-visible.ps1` 仅终止校验过的深色副本，拒绝终止另一个 Foxmail 可执行文件；等待旧进程退出再正常显示启动。不得用 Hidden 启动 GUI。

原生 fixture 使用固定已有的已编译测试器，修改其明确 CIL 常量/等长字符串后运行；不依赖全局 C# 编译器。完整重建仍受先前 README 所述固定测试依赖限制。没有将局部原生/导出检查冒称端到端视觉验收。
