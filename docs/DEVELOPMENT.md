# 维护说明

主分支维护安装器、当前增量补丁及其必要测试。历史研究不再逐文件堆在主分支。

## 重建分发入口

`tools/build.py` 使用 Python 标准库，读取 v5.1.0 Release ZIP，核对 SHA-256、安装器源码和默认配置，
再组合主分支的 CMD/PowerShell 源码。输出必须与已验收的正式 CMD 逐字节一致。
ZIP 是明确的外部输入，包含基础差分、模板、图像和已编译辅助 DLL；这些不在源码中重复存放。

`tests/test_build.py --kit <ZIP> --output-directory <新目录>` 检查精确重建、输入变更拒绝、已有输出保护和相对模块依赖。

## 原生补丁

`src/version587` 保留目前维护的托盘防护、写信字色、搜索和首次擦底修复，以及对应合成指令测试。
这些步骤依赖固定前像、阶段证据和登记工具环境，不能直接套用于别的版本。
`src/native` 将正式 helper 对应的生成后 C 源码集中保留，替代多轮中间生成器副本。
helper 源码前像 SHA-256 为 `b2523e50abc895f93ebc222ac3edcfe81f26dc20ee72b13508a4105c1ccf73aa`；
已发布 helper 的 SHA-256 为 `0e471e40cb64e5acf13d22a129849110b0ad2d21d7d4c7110036892aaa135c70`。

主分支的 CMD 重建不重新编译 helper。更改原生代码需要完整 ABI、生命周期和真实界面验收。
早期基础主题生成、辅助模块编译及旧诊断入口可在 `research-history` 分支查阅。

## 历史与发行

研究分支指向整理前的公开快照；主分支也保留其全部祖先提交。没有重写、压缩或删除 Git 历史。
v5.1.0 标签及四个 Release 文件保持原样，因此已发布版本的源码快照仍对应当时的目录。
目录整理只改变当前主分支，不更改已验收程序和补丁文件。
