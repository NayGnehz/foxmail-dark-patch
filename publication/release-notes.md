Foxmail 深色补丁 v5.1.0 正式版，适用于 Windows Foxmail 7.2.25.587 的指定原版文件。

首次使用请下载 **Foxmail-Dark-Patch.cmd**，完全退出 Foxmail 后，将它放到 `Foxmail.exe` 同级目录双击运行。
安装后仍运行 `Foxmail.exe`；需要恢复时，退出 Foxmail 后再双击同一 CMD。

本版合并深色界面、写信收件人和抄送人字色、搜索对比度、选人列表及收取弹窗首次擦底修复，
并包含托盘恢复时的辅助功能失效节点读取防护。

- 使用 Windows 自带 PowerShell 5.1，不需要 PowerShell 7。
- 原件移到 `原版备份`；恢复时保留文件创建时间和修改时间，并清理工具备份。
- 当前清单为 41 个软件文件；支持恢复前版备份。
- 文件指纹不匹配会停止，不支持直接应用于其他 Foxmail 版本。
- 已通过合成指令/像素检查、CMD 安装还原及用户真实界面验收。

旧补丁用户：先用新版 CMD 恢复原版，再运行一次安装新版。
